# nexa plugins

a few plugins i use on nexa. paste the file into nexa's plugin box and turn it on.

## whats in here

- **mass-accounts.min.js** - every account you saved, in one panel. switch between them, add more than the menu allows, join servers with all of them, set tags and pfps, leave servers, sync them everywhere. if you want the mass join captcha solved automatically, drop your own yescaptcha key into the settings.
- **toolbox.js** - self react, auto react to people, edit and delete logger, message stats, status and display name rotation, profile and mod helpers, emoji picker, silent typing.
- **say.js** - send the same message from every saved account at once, and rename them all together.
- **rpc-presence-rotation.js** - rotates your rich presence, with last.fm support.

## how to use

open nexa, go to plugins, paste one in, enable it.

a couple of them share the account list, so load mass-accounts first if you want the others to pick up your accounts.
